# /weekly — CLD 6단계 전체 실행

CLAUDE.md(SSOT)의 §2 파이프라인을 실행한다. 파라미터는 config/params.yaml만 참조.

## 사전 점검 (HARD 4 오염 금지)
1. 이 세션에서 `/tdy-input`이 먼저 실행됐다면 **중단**하라 (같은 세션 연속 실행 금지, 역순만 허용).
2. STEP 2~4 판단 중 `portfolios/tdy.json` 로드 금지, 팀더윤쎈 관련 검색·열람 금지(웹검색 포함).

## 절차
1. **데이터 수집**: 평가일 기준 Fwd PER(실패 시 트레일링 폴백), 국고10년(ECOS 우선),
   스코어카드 5항목 원천 데이터, KOSPI 섹터 BM 비중을 수집한다.
   자동수집 불가 항목은 웹검색으로 확보하되 **출처+asof 병기**, `data/manual/<날짜>.json`에 기록.
   확보 실패는 N/A(사유) — 날조 금지(HARD 1). 소스 상충 시 병기+채택 기준(HARD 2).
2. **판단 (Claude 자율)**: 스코어카드 채점(각 -1/0/+1, 근거+출처), 재량 오버라이드(사유 3줄+),
   섹터 목표(±7%p, 단일 35% 한도), 종목 선정(10~20개, 상한 10%, 최소 2%, 상위5 ≤45%, 선정 카드 필수).
   결과를 `state/inputs/<날짜>/judgments.json`에 기록한다.
3. **실행**: `python3 -m src.rebalance --date <날짜>` — 계산·검증·state/ledger/리포트 생성.
   가드레일 위반 시 포트폴리오 출력 없이 위반 보고(HARD 6), 판단을 수정해 재실행.
4. **대시보드**: `python3 -m src.dashboard`로 `reports/dashboard.html` 재생성 후
   기존 아티팩트 URL에 재게시(주차별 label 부여).
5. **Notion 동기화** (Notion 커넥터가 있는 세션에서만): 상황실 페이지
   (id 3bb2a34c-89a7-81ba-9ff1-ca41d2e01396)의 배분·섹터·종목·배틀 현황 표를 갱신하고,
   주간 리포트를 서브페이지로 추가. 커넥터 없는 자동 세션은 건너뛰고 다음 연결 세션에서 보충.
6. **기록**: CHANGELOG.md에 실행 기록 1줄 추가. 리포트 요약을 사용자에게 보고.
